# آزمایش‌یار هوشمند شهرام نادریان

نسخه نمایشی اولیه و دوزبانه (فارسی/English) برای ثبت و مرور برگه‌های آزمایش.

## اجرا
این پروژه یک وب‌سایت ایستا است. فایل `index.html` را در مرورگر باز کنید یا از GitHub Pages منتشر کنید.

## امکانات این نسخه
- رابط کاربری فارسی و انگلیسی
- انتخاب فایل تصویر یا PDF و پیش‌نمایش تصویر
- فرم ثبت اطلاعات پایه

## محدودیت‌های پزشکی و فنی
در این نسخه هیچ فایلی به سرور ارسال نمی‌شود و تحلیل هوش مصنوعی انجام نمی‌گیرد. برای تحلیل واقعی، به سرویس پشتیبان امن، پردازش تصویر، کنترل دسترسی و بازبینی پزشکی نیاز است. این نرم‌افزار ابزار تشخیص یا جایگزین پزشک نیست.

## انتشار
Workflow موجود در `.github/workflows/pages.yml` با هر push روی شاخه `main` تلاش می‌کند سایت را روی GitHub Pages منتشر کند. در تنظیمات مخزن، بخش **Settings → Pages → Build and deployment** را روی **GitHub Actions** قرار دهید.
