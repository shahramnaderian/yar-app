# یار (Yar) — دستیار هوشمند شخصی

**یار** یک عامل هوش مصنوعی شخصی (Personal AI Agent) است که کارها را واقعاً انجام می‌دهد.

## محتویات پروژه

| مسیر | توضیح |
|------|--------|
| `web-prototype/index.html` | پروتوتایپ وب — در مرورگر باز کنید |
| `flutter-skeleton/` | اسکلت اپ Flutter |
| `backend/` | API اسکلت Node.js |
| `docs/` | مشخصات محصول، UI/UX، مدل کسب‌وکار |

## اجرای سریع

```bash
# پروتوتایپ
open web-prototype/index.html

# بک‌اند
cd backend && npm install && npm start
```
